# Progress Analyzer

Học Rust bằng cách build 1 desktop app thật (Tauri + Leptos),
phân tích tiến độ NeetCode 150 từ README của repo neetcode-150-rust.

## Chạy project

git clone https://github.com/Hinggg-itmn/progress-analyzer.git
cd progress-analyzer
cargo tauri dev
